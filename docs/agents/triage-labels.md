# 分诊用词

`triage` 技能按五个固定的状态角色来说话。这个文件把这五个角色对成本仓库真正用的词。
本仓库不用标签，词写在每个 issue 文件顶部的 `Status:` 那一行。

| 技能里的角色名 | 本仓库用的词 | 意思 |
| --- | --- | --- |
| `needs-triage` | `待分诊` | 维护者还没看过、没定过 |
| `needs-info` | `待补充信息` | 等报告的人补信息 |
| `ready-for-agent` | `可交给AI` | 说清楚了，可以交给 AI 自己去做 |
| `ready-for-human` | `需人工` | 得人来动手 |
| `wontfix` | `不做` | 决定不处理 |

另有两个分类角色，每个分诊过的 issue 要有一个：

| 技能里的角色名 | 本仓库用的词 | 意思 |
| --- | --- | --- |
| `bug` | `缺陷` | 有东西坏了 |
| `enhancement` | `改进` | 新功能或改进 |

技能里提到某个角色时（比如「打上 ready-for-agent 的分诊标记」），就用右边这一列的写法。
想换词就改「本仓库用的词」这一列。
