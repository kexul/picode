# Pi Chat 提醒（安卓 app）

手机上收「会话跑完一轮 / 模型在等你答一句」的通知，不靠微信。

界面就一屏：没有标题栏、也没有自己的一条横条，整屏就是网页端本身（跟手机浏览器打开后端那个地址看到的一样，能看会话、能接着聊）。
填地址那一块平时收着：点通知栏里那条常驻通知，app 打开并把它摊开（再点底下那句「收起」，或者按返回键，就收回去了；存完也自己收起）。
地址还没填时它自己摊开，那时也收不起来（那时通知栏里还没有那条常驻通知，收起来就再没入口了）。
连接状态不常驻屏幕上：平时看通知栏那条常驻通知（「已连上 / 重连中…」），摊开那块时底下那行小灰字也写着。
网页打不开（地址写错、后端没开）时也自己摊开。

## 怎么用

1. 装上去，打开，填后端地址 —— 就是你在浏览器里打开 Pi Chat 时那个地址，例如
   `http://100.73.225.24:51883`（只写 `100.73.225.24:51883` 也行，会补上 `http://`）。
2. 点「保存」。那行收起来，网页端出来了，通知栏里出现一条常驻的「Pi Chat」。
3. 之后某台后端里跑完一轮、或者模型在等你答一句，手机就弹一条：标题是会话名（别的机器推来的前面带那台的名字），
   底下是回复开头；点它，app 打开并切到那个会话。

- 通知栏里那条常驻的（写着「已连上 / 重连中…」）别关掉也别嫌它碍事：它就是那个前台服务，关掉系统很快就会把后台连接掐了，通知就收不到了。app 里没有关它的开关：地址填了就一直挂着（想改地址、看连接状态，点它一下）。
- 这一路跟着后端设置里那颗「弹窗通知」走：那儿关掉，手机上也不再弹（跟微信那条互不相干，微信有自己一颗开关）。

## 安卓上要做的几件事

- **允许通知**（Android 13 起第一次打开会问；问过以后在系统设置 → 应用 → Pi Chat 提醒 → 通知里改）。
- **允许自启动 / 后台运行白名单**（小米的「自启动」、华为的「应用启动管理」、OPPO/vivo 的「允许后台运行」这类）。
  不做的话，系统把 app 杀掉以后就收不到，得自己再打开一次。
- **电池优化设成「不限制」**（同一个应用详情页里），不然连着连着会被冻住。
- 锁屏上要看得见、要响，就在通知设置里把「会话提醒」这颗通道设成「响铃 + 悬浮/锁屏显示」。

## 怎么工作

- 前端服务（那颗常驻通知）挂着一条到后端的连接：`GET /phone?client=<这台手机的标识>`，
  后端有「有事」就往这条连接上写一行 JSON，手机收到就弹一条。断了自动重连（刚断 2 秒后就试，
  一直连不上一路退到最多一分钟一次）。
- 漏掉的不补发：手机上少一条提醒不算事，点开 app 看会话就全都在。
- 点通知要切到那个会话，走的是后端现成的那条路（`POST /switch`，跟点右下角那张提醒卡一样），
  app 自己不去动网页里的东西。
- 没有口令：跟 `/notify` 一个规矩，机器对机器、不带 Origin —— 只在信得过的网络里用（同一个局域网、
  自己的 tailnet，或者前面挂的 https 反代）。

## 怎么编、怎么装

仓库里这份不引任何第三方库（纯 Android SDK：网页视图 + `HttpURLConnection` + 系统通知）。

```bash
cd android
./gradlew assembleDebug                       # 或者 Android Studio 直接打开这个目录
# 产物：app/build/outputs/apk/debug/app-debug.apk
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

- 要 JDK 17 以上、Android SDK（`compileSdk 36`）。没有 `./gradlew` 就用本机的 Gradle 8.13 以上直接跑：
  `gradle assembleDebug`。
- `local.properties`（`sdk.dir=...`）是这台机器的路径，不进版本库。
- 用 debug 签名就够：自己手机上装，不往上架。
