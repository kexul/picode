# Pi Chat 桌面小窗口

Windows 上的一个小程序，一份东西管三样事：

- **主界面**：长得像微信电脑版，左边一列会话，右边是这个会话里后端推过来的那些「有事」
  （这一轮跑完了说了什么、模型在等你答哪道题），底下能回一句。
- **通知区域里那颗图标**：后端一起来就出现。左键点它开主界面；右键三项 ——「打开主界面」、
  「打开网页端」（用浏览器打开这个后端的地址）、「退出」（连后端一起收摊，跟终端里按 Ctrl+C 一样）。
- **屏幕右下角那张提醒卡片**：哪个会话有事就弹一张（最多三张叠着），点它开主界面并选到那个会话，
  跑完一轮响两个音、等你答一句敲三下。

跟网页端、手机 app 看的是同一个后端、同一批会话。它只收消息、回消息、答题，不管会话本身怎么跑。

后端起来时会把它叫起来（`--hidden`：先只待在托盘里，不弹窗口）。窗口右上角那颗叉只是把窗口收起来，
托盘图标还在，左键点一下就回来。同一个程序只跑一个：再叫一次（双击、或者后端重启）只是把已经在跑的那个
叫出来、或者让它跟着换成新的后端地址。

## 怎么编

需要 .NET 8 SDK 或更新的 SDK（目标框架是 `net8.0-windows`，用系统自带的 WPF）。

```bash
cd desktop/PiChat
dotnet build -c Release
```

仓库根目录的 `build.bat` 也会顺手编它（不想要就加 `skip-desktop`）。

一个第三方包都不引：界面用 WPF、网络用 `HttpClient`、JSON 用 `System.Text.Json`，全是系统自带的。
所以不用还原 NuGet，也不用连网，`dotnet build` 直接过。

## 怎么跑

```bash
cd desktop/PiChat
dotnet run -c Release
```

或者直接开编出来的 exe（不用装 .NET SDK，装 .NET 8 桌面运行时就行）：

```text
desktop/PiChat/bin/Release/net8.0-windows/PiChat.exe
```

起来以后默认连上次用过的地址（第一次是 `http://127.0.0.1:51991`）。地址在左下角那颗齿轮图标里改：
点它弹出一个小窗口，填完点「连接」（回车也行），改过以后记下来，下次打开还用它。

## 参数

| 参数 | 意思 |
| --- | --- |
| `--session <会话标识>` | 启动时直接选中这个会话 |
| `--url <后端地址>` | 这次用这个地址并记下来（后端叫它起来时带的就是这个） |
| `--hidden` | 起来只待在托盘里，不弹窗口（后端叫它起来时用这个） |

`--url=http://...` 这种带等号的写法也认。例：

```bash
PiChat.exe --url http://10.0.0.2:51991 --session remote:PC2:s-demo-1
```

## 记在哪儿

`%APPDATA%\PiChat\config.json`：

- 后端地址；
- 窗口的位置和大小；
- 上次选的会话。

窗口最小 600×400；关窗口（收到托盘里）时写一次。

出岔子的那几行记在 `%APPDATA%\PiChat\app.log`（这是个没有黑框的程序，界面上说不出话，
「点了没反应」的时候看这里）。

## 界面上的几点

- 左边一行一个会话：会话名、最后一条通知的第一句、时间（今天的写时刻，早的写日期）；
  在跑的有一颗蓝点；有还没答的题会写「在等你答一句」。
- 有通知的排前面，按最后一条的时间倒序。
- 窗口没有一条自己的标题栏行：会话名只在左边那一行写着，右边就是消息本身。
- 右边：`done` / `ask` 靠左（`ask` 是淡黄色），`me` 靠右（浅绿色）。
  正文按 markdown 画（`Markdown.cs`）：段落、标题、列表（项首对齐）、引用、代码块（能选、能横向滚），
  行内的粗体 / 斜体 / 删除线 / 行内代码 / 链接文字。跟网页端一样（那边用 marked，单个换行就是换行）。
  只做聊天里常用的那几样，表格、脚注这些不认。
- 题目下面是选项：单选 / 多选、可选的「自己写」一行、发送按钮；推荐的选项后面写「（我推荐）」。
  答完以后置灰并写明「已答：…」。在别处（网页上、手机上）答掉了的题，
  后端会推一条 `askdone`，这边同样置灰（断线重连后也记得）。
- 底下就一行：输入框跟「发送」一样高（单行），回车就发；提示语（回车发送 / 先挑一个会话）
  是输入框里的浅灰字，不另占一行。只有出错时才在输入框下面多出一行红字，写着后端给的原因。
- 左下角一颗齿轮图标（⚙，鼠标悬停写「设置」）跟一句连接状态（「已连上 / 重连中…」）：
  点齿轮弹一个小窗口换后端地址——里面也能看到现在连到哪儿了，填完点「连接」（回车也行），
  关掉窗口（或者按 Esc）就回去；地址记在 `%APPDATA%\PiChat\config.json`。
- `remote: true` 的会话（名字前面带「那台的名字 ·」那种）也能回：这句话转给原来那台
  （那边当成你说的一句，跟微信里引用一句回过去是同一条路）。列表上不再另加标签——
  名字前面那个前缀已经区分得开。
- 连不上后端时左下角写着「连不上后端，正在重连…（N 秒后再试）」，每 2 秒起、最多 30 秒试一次；
  连上以后写「已连上」。

## 一个环境上的坑

远程桌面、虚拟机、部分虚拟显卡上，WPF 走显卡渲染有时整块窗口只剩一片白（界面元素都在，就是画不出来）。
这个窗口很小，所以程序里固定用软件渲染（`Program.cs` 里那一行 `RenderOptions.ProcessRenderMode`），
换来在哪种机器上都能画出来。要改回显卡渲染，删掉那一行就行。
